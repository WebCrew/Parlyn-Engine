# Parlyn Samples

`Parlyn-Test-Project` is a small, redistributable test project bundled with the repository.

Use **Open Project** in Parlyn and select the `samples/Parlyn-Test-Project` folder. It exercises:

- project metadata loading
- scene loading
- `Sprite2_5D`
- `Billboard2_5D`
- `Mesh3D`
- `Light3D`
- `Camera3D`
- project asset listing

The sample assets are created specifically for Parlyn and may be used for testing the engine.
