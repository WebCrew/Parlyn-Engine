# Parlyn Engine v0.5.0 Beta 17 — Maintainer Acceptance

Beta 17 establishes the compact Parlyn Command Bar. Frequent viewport commands
use original inline SVG icons, while central modes keep short text labels.

1. Confirm Select, Move, Rotate and Scale show four distinct, legible icons.
2. Hover each icon and confirm its name and shortcut appear in the tooltip.
3. Switch through Q/E/W/R and the buttons; the active tool must remain obvious.
4. Confirm Snap has a magnet-style icon and a separate dropdown arrow for its
   settings. Test both controls.
5. Toggle World/Local and confirm its compact text changes correctly. Select
   Scale and confirm Local is shown and disabled as before.
6. Confirm Ground uses the downward-to-surface icon and still works by click
   and the End key.
7. Confirm the 2.5D/3D selector retains text and both views work.
8. Resize and hide panels and confirm the Command Bar stays on one line without
   overlapping the viewport or Inspector.
9. Re-test Undo/Redo, saving and reopening a project.

No new editor command is introduced by this release.
