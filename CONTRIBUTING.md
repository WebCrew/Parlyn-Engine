# Contributing to Parlyn Engine

Parlyn Engine is open source, but its architecture is still young and intentionally **maintainer-led**.

## What is welcome now

- reproducible bug reports
- regression reports
- platform compatibility reports
- editor workflow feedback
- small test cases
- documentation corrections

## Pull requests

Please do not assume that a technically correct pull request will automatically be merged.

During the foundation phase, core architecture and merge decisions remain with the Parlyn maintainers so scene formats, renderer boundaries and editor conventions can stabilize coherently.

For substantial code changes, opening an issue or discussion first is strongly preferred.

## Later

Once the architecture is stable, Parlyn intends to publish clearer rules for coding conventions, module boundaries, testing, review and long-term contributor responsibilities.

The goal is to open development carefully rather than prematurely.
